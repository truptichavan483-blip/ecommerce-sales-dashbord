# E-commerce Sales Dashboard

## Overview
An interactive E-commerce Sales Dashboard created using Power BI
to analyze sales performance and business trends.

## Tools Used
- Power BI
- Power Query
- DAX
- Excel

## Dashboard Features
- Total Sales
- Total Profit
- Total Orders
- Sales by Category
- Sales by Region
- Monthly Sales Trends
- Interactive Filters

## Skills Demonstrated
- Data Cleaning
- Data Transformation
- Data Analysis
- DAX
- Data Visualization
- Dashboard Development
